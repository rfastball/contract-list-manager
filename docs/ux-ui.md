# 계약 목록 UX / UI

## 작업 방향

모드: Operate. 기존 글꼴·색상·테마를 유지하고, 자료 탐색과 실행할 작업의 위계를 정리한다.
주 사용 환경은 Windows 데스크톱이며 좁게 줄인 창에서도 조작할 수 있어야 한다.

## 작업 흐름

1. **넣기** — 자료는 브라우저 확장 수집과 설정의 ERP JSON 검토로 들어온다(ADR-028).
   자료가 없으면 그 두 길을 한 줄로 안내한다. 계획 목록에서는 계획 엑셀 설정으로 안내한다.
2. **찾기** — 왼쪽의 통합·계획·접수·공고·계약·현황에서 범위를 정한다.
   검색은 현재 화면에 적용되고 결과 건수와 전체 건수를 함께 보인다.
3. **검토** — 통합 구조에서 접수·공고·계약을 같은 줄로 읽는다.
   ‘빈 단계 있는 건’은 접수 또는 공고가 없거나 계약이 0건인 조달 건만 남긴다.
   이것은 저장된 자료의 빈 자리이며 실제 업무 누락이나 진행 지연의 판정이 아니다.
4. **연결·수정** — 공고 연결에서 근거를 비교해 결정하고, 표 보기에서 기존 키보드로 편집한다.
   차수 보기의 읽기 전용과 삭제 전 영향 확인은 그대로 유지한다.
5. **내보내기** — 엑셀로 내보내기는 상단의 유일한 동작이다. 제출·취합은 기존 설정 화면에 있다.

## 첫 화면과 상호작용

- 왼쪽 탐색 / 제목·설명 및 입출력 / 자료 수·보기 방식 / 검색 / 조달 흐름 순서.
- 핵심 상호작용은 빈 단계 필터와 검색의 결합. 결과가 없어도 조건 초기화로 복구한다.
- 빈 자료, 검색 결과 없음, 읽는 중, 오류 알림을 구분한다. 오류는 보조기술에도 알린다.
- 탭은 방향키·Home·End, 검색은 Ctrl+F, 표와 구조는 기존 이동·편집 단축키를 유지한다.
- 760px 이하에서는 탐색을 위로 옮기고 단계는 세로로 잇는다. 표는 자체 영역에서 가로 스크롤한다.
- 개발 브라우저에는 ‘미리보기 · 예시 자료’를 표시한다.
- 화면 전환 중 이전 응답은 버리고, 읽기 실패에는 ‘다시 읽기’를 제공한다.
- 구조에서 선택한 건은 표 검색과 연결 검토로 이어진다. 차수 내역은 펼쳐 읽으며 검색 중에도 접기·초기화가 가능하다.
- 설정·확인 창은 네이티브 dialog의 초점 제한과 Esc 닫기를 사용한다. 현황의 이름·건수 전체가 필터 단추다.
- 확장 연결 도움말은 앱 실행, 권한·호스트 등록, 새로고침 순서로 복구를 안내한다.

## 보완 검증 (2026-09-24)

- 기존 테스트 파일에 회귀 사례 2개를 추가했다. 지연된 이전 응답의 덮어쓰기 방지와 선택 건의 표·연결 이동은 App 테스트가 담당한다. 접기·차수 표시·현황 단추·누락된 연결 대상·확인창 초점은 기존 소유 테스트를 확장하고 이전 표시 방식의 단언을 교체했다.
- 테스트 7개 파일, 100개 통과. 직전 98개/11.49초에서 100개/13.14초로 증가했다(통제된 성능 비교는 아님). 새 테스트 파일·의존성·CI 경로·무거운 자동 실행은 없으며 coverage 기준은 유지했다.
- 프런트엔드 빌드와 별도 출력 경로의 WPF 빌드가 통과했다. WPF 경고·오류는 0개다.
- 브라우저에서 넓은 창과 760px 창, dialog 초기 초점·Esc 복귀·배경 비활성화, 차수 Enter 펼치기, 선택 접수의 표 이동을 확인했다. 확장 미리보기는 280px 저장 결과 조회·동일 요청 재시도·성공 흐름과 360px 연결 도움말을 확인했다. 280px 가로 넘침은 없었다.
- 대시보드 콘솔 오류는 없었다. 확장 미리보기 로그에 발생 위치를 확인하지 못한 MutationObserver 오류 1건이 있었으나 확인한 흐름은 완료됐다. 실제 설치 확장→나라장터→NativeHost→DB 경로는 이번에 실행하지 않았다.
- 최종 정적 탐지 10건은 확장의 기존 테마 색·그림자·독립 글자 크기와 글꼴 이름 파싱 경고였다. 비활성 단추 hover 대비 지적은 제거됐다. 새 글꼴 파일이나 디자인 의존성은 추가하지 않았다.

## 구현 범위

기존 컴포넌트와 공유 토큰을 사용한다. 백엔드·데이터 계약·파싱·문서 연결 판정은 변경하지 않는다.
현황 지표의 업무적 타당성, 원문 옆판, 신규 데이터 필터·열 선택은 이번 구현에 포함하지 않는다.
