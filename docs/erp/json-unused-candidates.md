# 미사용·제외 가능성이 높은 항목 일괄 검토

상태: **사용자 전체 제외 확정**. A1~A7·B1~B5의 12개 묶음, 출처별 122개 필드를 MVP 업무 매핑·계산·표시에서 제외한다. 구현 전 범위 확정이며 런타임 코드는 변경하지 않았다.
전수조사 15개 JSON 중 계약 5개·대표 품목 26행·업체 5행의 관찰을 중심으로 선별했다.
빈값/0만 나온다는 사실은 일반적으로 무의미하다는 증거가 아니다. 아래 A/B 구분은 당시 제안 근거를 보존한 것이며 현재는 모두 제외로 확정되었다.
용어는 사용자 확정 전에는 여전히 후보이며 실제 사용 여부와 정확한 라벨은 별개다.
업체표·품목표·pointInfo를 구분한다. 품목표 제외는 동일 내용인 Excel 품목표에도 적용한다. 명시한 출처 밖의 동명 필드로 확대하지 않는다.
이미 제외한 업체표 ctrtGrnteAmt/cgntTxam/incmCgntPchaAmt, 품목표 ctrtGrnteAmt, 접수 advfGivePsbltyYn/advfGivePsbltyRat는 다시 승인받지 않는다.
후속 결정으로 공동수급 방식·역할·분담 관련도 **코퍼스 확보까지 미사용**이다.
이는 아래 122개 필드와 별도 결정이며 업체별 현재차수 계약지분율·지분금액은 유지한다.
최신 승인·보류는 [일괄 답변 반영](json-field-questions.md#일괄-답변-반영-2026-09-27)을 따른다.

## 이 일괄 제외 제안에 넣지 않은 항목

- 현재 계약차수의 업체별 계약지분율·지분금액과 공동수급 구성 상세는 유지한다.
- 전체지분율·전체지분금액 `wholSharRat`·`wholSharAmt`는 후속 사용자 방침으로 미사용 보류했다.
  pointInfo·업체표 모두 분류·용어 후보만 남기고 당장 업무 매핑·계산·표시에 사용하지 않는다.
- pointInfo의 계약보증금률·보증금액, 인지세 부과액, 선급금 선고지 비율, 접수의 선고지 가능 비율.
- 납기·검사·하자·지체상금 조건, 기존 PDF 수집 정보, 명시적 연결 키.
- 부가세 포함 여부·세율은 당시 일괄 목록 밖이었다. 후속 결정으로 업체표 `vatIncsYn`·`vatRat` 2개는 추가 제외했다. pointInfo의 동명 필드와 `vatAmt`는 이 결정의 대상이 아니다.
- 실제 값이 있는 완제품 원산지, 정확한 뜻이 아직 없는 정책 플래그. N/0만으로 불필요하다고 보지 않는다.
- 0행인 표 전체. 공동수급 보증업체 표처럼 표본에 없을 뿐 필요한 구조일 수 있다.
- 일반 계약조건 ctrtCndtCn. 기타 계약유형 부근에 있다는 이유만으로 일괄 제외하지 않는다.
