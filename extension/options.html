페이지 수집기 표시

버튼으로만 열면 나라장터 화면을 관찰하지 않습니다. 저장 결과를 확인하지 못한 요청이 있으면 툴바 버튼에 ! 가 붙습니다. 바꾸면 열린 나라장터 탭에 바로 반영됩니다.

연결 환경

개발용 앱(--erp-dev)과 함께 쓸 때만 켭니다. 업무 DB에 저장하려면 끕니다.

저장 위치 확인 중

그 안에 폴더를 만들어 옮깁니다. 실제 이동은 계약 목록 앱을 다음에 실행할 때 이루어지며, 그때까지는 지금 자리에 저장됩니다.

단축키

단축키 확인 중

단축키를 누르면 현재 화면을 확인하고, 고를 충돌·대응하지 못한 품목·결과를 확인하지 못한 저장이 없을 때만 바로 저장합니다. 하나라도 있으면 저장하지 않고 검토를 기다립니다.
