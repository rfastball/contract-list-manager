페이지 수집기 표시

버튼으로만 열면 나라장터 화면을 관찰하지 않습니다. 저장 결과를 확인하지 못한 요청이 있으면 툴바 버튼에 ! 가 붙습니다. 바꾸면 열린 나라장터 탭에 바로 반영됩니다. 수집기의 「숨기기」 와 툴바 버튼 팝업에서도 바꿀 수 있습니다.

연결 환경

개발용 앱(--erp-dev)과 함께 쓸 때만 켭니다. 업무 DB에 저장하려면 끕니다.

단축키

단축키 확인 중

단축키를 누르면 현재 화면을 확인하고, 고를 충돌·대응하지 못한 품목·결과를 확인하지 못한 저장이 없을 때만 바로 저장합니다. 하나라도 있으면 저장하지 않고 검토를 기다립니다.
